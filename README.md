# Team Library Management

Demo project for a GitHub group-work presentation.

## Features
- Add books
- Display books
- Search books
- Delete books
- Borrow/return status
- LocalStorage data persistence

## GitHub workflow demonstrated
Repository → Branch → Commit → Push → Pull Request → Review simulation → Merge → Issue → Bug fix

> Presentation note: This demo uses one computer and one GitHub account.
> The five members are simulated as presentation roles; GitHub identity is not faked.
